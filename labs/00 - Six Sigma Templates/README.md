# Six Sigma Templates

Reusable Lean Six Sigma templates that support the activities in this course.
They are generic templates — not tied to one activity — so they live here rather
than inside a numbered activity folder.

| Template | Used in |
|----------|---------|
| `08 Project Charter Template.xlsx` | Activity 05 — Project Charter |
| `20 Swimlane Chart.xlsx` | Activity 07 — Process Mapping and Swimlane Analysis |
| `23 Kano Analysis.xlsx` | Activity 03 — Voice of the Customer and Kano Analysis |
| `51 Fmea_Template.xls` | Activity 22 — FMEA and Risk Priority Numbers |
| `52 Selection_Solution_Matrix_Template.xlsx` | Activity 21 — Solution Selection Matrix |
| `53 Implementation_Plan_Template.xlsx` | Activity 22 — Piloting |
| `54 Control_Plan_Template.xlsx` | Activity 24 — Control Plan |
| `Six Sigma templates guides.pdf` | Reference for all of the above |

Each numbered activity folder has its own `data/` folder holding the Northwind
dataset for that activity. These templates are the blank forms you fill in with it.
